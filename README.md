Leonida Nights — a GTA-style cover maker: drop in your photo, place it across a multi-panel poster with drawn Vice City scenes, write a bold caption, and export a PNG in the common post sizes (1080×1080, 1080×1350, 1920×1080). Runs fully offline in a desktop browser; your photos never leave your machine. All art is drawn by the app itself — 100% original, no Rockstar assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
